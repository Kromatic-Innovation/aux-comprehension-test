# Ground truth: mini fixture

## estimate_run_cost

Predicts the credit cost of a simulation run before running it. Free, read-only.

- Misreading: It forecasts the probability of an event.

## forecast_probability

Forecasts the probability of an event happening by a date. Costs one credit.

- Misreading: It estimates what a simulation run costs.

## delete_saved_report

Permanently deletes one saved report by id; irreversible. Free.

- Misreading: It archives the report and can be undone.
